# Referencias bibliográficas del proyecto MEMRISTORES

Este directorio contiene referencias, resúmenes propios y clasificación
de literatura científica relacionada con el proyecto.

Los archivos PDF originales se conservan externamente en Google Drive
y no forman parte de este repositorio.

## Tema principal

**Relación entre enfermedad de pequeño vaso cerebral y hallazgos
estructurales compatibles con parkinsonismo vascular mediante
resonancia magnética.**

## Clasificación

- `DIRECT_EVIDENCE.md`: evidencia directamente relacionada con el tema.
- `METHODOLOGICAL_SUPPORT.md`: artículos de apoyo metodológico o tecnológico.
- `EXCLUDED_ARTICLES.md`: artículos evaluados y descartados.
